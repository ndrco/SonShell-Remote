# Работа с приложением

- «Сохранить имя и пароль» сохраняет оба поля на этом компьютере. Снятие флажка
  сразу удаляет их из настроек. Файл приватный (0600), без шифрования.
- Без сохранения поля остаются в памяти текущего окна для переподключения.
- Auto Sync применяется сразу и после каждого восстановления; Sync All передаёт
  все доступные файлы. Передача RAW поддерживается backend, просмотр пока JPEG/PNG.
- Каталог можно менять при отключённой камере; он используется и для передачи,
  и для поиска последнего завершённого JPEG. Подкаталоги также просматриваются.
- Live View встроен в первую вкладку. «Вписать», «100%», +/− и колесо меняют
  масштаб; зажатая левая кнопка перемещает изображение.
- Полный экран — кнопка или F11 с фокусом в просмотрщике. Esc возвращает обратно.
- Последняя фотография — во второй вкладке. Кнопка отдельного окна сразу включает
  100% оригинала, доступны масштаб, панорамирование и полный экран.
- Подключение определяется событиями SDK. При обрыве управление отключается;
  повторы через 3, 6, 12, 24, затем 30 секунд. «Отключить» отменяет их.
- При ошибке пароля остановить повторы, исправить поля и подключиться снова.
- Студийный показ, галерея, EXIF и AF по клику пока запланированы в ROADMAP.md.

Настройки: `~/.config/SonShellRemote/settings.ini`. Прототип использовал другой
путь; новый проект его настройки не меняет. Не прикладывать файл настроек и
fingerprints к публичным сообщениям об ошибке.
