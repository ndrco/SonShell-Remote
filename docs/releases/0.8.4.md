# SonShell Remote 0.8.4

English is now the default application language. Russian remains available in
Settings → Language, and existing saved language preferences are retained.

## Download and install

**Target: Ubuntu 24.04 amd64 (Intel/AMD 64-bit).** Download the DEB and
SHA256SUMS from this release into the same directory:

```bash
sha256sum -c SHA256SUMS
sudo apt update
sudo apt install ./sonshell-remote_0.8.4-1ubuntu24.04_amd64.deb
```

The package includes the GUI, backend and Sony runtime. apt installs Qt,
ExifTool, FFmpeg and other Ubuntu dependencies; a separate SDK or compiler is
not required on the target machine.

## Changes

- English source messages, default/fallback language and backend diagnostics.
- Complete Russian Qt catalog and retained `_RU` documentation, help and metadata.
- Both user-guide languages are installed with the application.
- README uses the owner's supplied screenshot; the former demo caption was removed.
- Requested local development documents and their links were excluded from source.

Existing camera features are retained: embedded Live View, exposure dials,
click-to-focus, card review and selection, RAW/JPEG/video import, date-based
folders, SHA256 checks, studio review and full-screen video controls.

## Verification and limits

- CMake GUI/backend build; CTest offscreen **9/9**.
- AddressSanitizer **5/5** with leak detection disabled.
- Fresh Ubuntu Base 24.04.5 amd64 installation, English/Russian runtime,
  upgrade from 0.8.3, installed binary checksums and removal.
- No new physical-camera acceptance run was performed for this language update.

This project is in development. Other Ubuntu versions and ARM need separate
builds. RAW viewing uses an embedded JPEG; video preview has no audio. Main
video playback downloads the full original, while optional SDK streaming may
fail to deliver video frames on some camera/clip combinations.
