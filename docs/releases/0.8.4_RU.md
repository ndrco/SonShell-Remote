# SonShell Remote 0.8.4

Английский стал языком приложения по умолчанию. Русский доступен через
«Настройки → Язык»; сохранённый выбор языка сохраняется при обновлении.

## Установка

**Ubuntu 24.04 amd64 (Intel/AMD 64-bit).** Скачай DEB и SHA256SUMS из релиза
в один каталог:

```bash
sha256sum -c SHA256SUMS
sudo apt update
sudo apt install ./sonshell-remote_0.8.4-1ubuntu24.04_amd64.deb
```

GUI, backend и runtime Sony входят в пакет. Qt, ExifTool, FFmpeg и остальные
зависимости устанавливает apt; отдельный SDK или компилятор не требуется.

## Изменения

- Английские исходные строки, язык по умолчанию и диагностика backend.
- Полный русский Qt-каталог; русская документация, справка и metadata в `_RU`.
- В пакет входят оба языка руководства пользователя.
- В README установлен скриншот владельца проекта; прежняя подпись удалена.
- Указанные служебные документы и ссылки на них исключены из исходников.

Сохранены Live View, крутилки экспозиции, AF мышью, отбор на карте, импорт
RAW/JPEG/видео, каталоги дат, SHA256, студийный просмотр и полноэкранное видео.

## Проверки и ограничения

- Сборка GUI/backend, CTest offscreen 9/9.
- AddressSanitizer 5/5, без проверки утечек.
- Чистая установка Ubuntu Base 24.04.5 amd64, запуск обоих языков,
  обновление с 0.8.3, контроль установленных бинарников и удаление.
- Новая аппаратная приёмка для этого языкового обновления не проводилась.

Проект развивается. Другим Ubuntu и ARM нужны отдельные сборки. RAW показывается
через встроенный JPEG; видео без звука. Основной Play скачивает оригинал целиком;
необязательный SDK-поток на некоторых сочетаниях камеры и ролика не отдаёт видео.

## Условия

Код приложения — Apache-2.0. Для runtime Sony действуют отдельные
[условия Sony](https://support.d-imaging.sony.co.jp/app/sdk/licenseagreement/en.html),
включая положения о гарантии устройств и ограничения использования.
Ознакомься с ними перед использованием SDK; приложение показывает их перед
первым подключением. Официальный текст и OSS notices входят в DEB.
Приложение независимо от Sony; поддержку предоставляет NDRco.
