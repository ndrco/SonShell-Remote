## Этап 2 — медиатека и передача

- Локальная галерея: миниатюры, сортировка, поиск, пары RAW+JPEG.
- RAW: сначала встроенный JPEG preview; полноценное проявление через LibRaw
  отдельным решением. Не называть встроенный JPEG полным RAW-разрешением.
- EXIF через Exiv2: ориентация, камера, объектив, экспозиция, время, цветовой профиль.
- Auto Sync, Sync All и каталог уже есть в прототипе: сохранить, затем добавить
  очередь, прогресс, отмену, дедупликацию и восстановление передачи.
- Открывать только завершённые передачи: событие backend и атомарная публикация.

Готовность: проверены новая съёмка и большая карта, пары RAW+JPEG, отсутствие
дублей при повторном Sync All; ошибки и нехватка места видны пользователю.

- Загружать оригинал, поддерживать 100%; не подменять его кадром Live View.
- При RAW+JPEG использовать JPEG до готовности RAW preview; показывать источник.

Готовность: таймер запускается по готовности файла, новый снимок обновляет таймер;
потеря связи/закрытие окна не оставляют интерфейс в зависшем режиме.
