## Этап 2 — просмотр карты и отложенный импорт (уточнение 0.4)

Исходный сценарий 0.3 был ошибочным: локальная галерея и Auto Sync оригиналов
не заменяют просмотр карты после съёмки. Основной сценарий: съёмка без передачи
RAW → список карты → сжатые превью → отбор/удаление брака → явное копирование.

- [x] Отключить GUI Auto Sync оригиналов, включая старые сохранённые настройки.
- [x] Отдельные вкладки «В камере» и «На компьютере · EXIF».
- [x] Каталог обоих доступных слотов, RAW/JPEG, превью SDK без скачивания RAW.
- [x] Раздельные отметки копирования/брака, все/новые/отмеченные, фильтр форматов.
- [x] Удаление кадра с подтверждением состава; защита/доступность и terminal callback.
- [x] Каталог назначения, последовательная очередь, прогресс/отмена, атомарная
  публикация и журнал успешного импорта, проверка размера, отказ от перезаписи.
- [x] Локальная галерея, EXIF и встроенные JPEG RAW (0.3).
- [ ] Аппаратная проверка превью, двух слотов, удаления и импорта большой карты.
- [ ] Профилирование больших карт, виртуальный список/пакетное обновление статусов.
- [ ] Сверка копий хешами и возобновление отдельных файлов по диапазонам, если SDK позволяет.
