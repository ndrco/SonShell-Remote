## Локальная связь с GitHub

Текущая локальная ветка переименована из master в main, origin указывает на
https://github.com/ndrco/SonShell-Remote.git и отслеживается origin/main.
Прежние remotes prototype/upstream сохранены. Исходный прототип не менялся.
Аутентификация push выполнена существующим gh через разовую опцию Git;
глобальные Git-настройки и службы не менялись.

Чтобы отменить только эти локальные настройки связи и имя ветки, находясь
в main без другой локальной master:

```bash
git branch --unset-upstream main
git remote remove origin
git branch -m main master
git branch --set-upstream-to=prototype/master master
```

Это не удаляет опубликованный репозиторий и не переписывает историю.
